# Password Strength Checker

Εργαλείο (CLI) για την αξιολόγηση της ισχύος κωδικών πρόσβασης, βασισμένο σε:

- Υπολογισμό εντροπίας
- Έλεγχο έναντι κοινών/λεξικών κωδικών (dictionary/pattern checks)
- Κανόνες σύνθεσης (μήκος, χαρακτήρες, επαναλήψεις)

## Εκτέλεση

```bash
cd password-strength-checker
pip install -r requirements.txt
python main.py
```

> Δες το `README.md` μέσα στον φάκελο του project για αναλυτικές οδηγίες
> χρήσης και τη μεθοδολογία αξιολόγησης.
