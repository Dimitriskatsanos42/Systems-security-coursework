# Assignment 1 — Hashing, Εντροπία & 2FA

Υλοποίηση εννοιών γύρω από ακεραιότητα δεδομένων και αυθεντικοποίηση:

- Υπολογισμός hash (π.χ. SHA-256) για επαλήθευση ακεραιότητας αρχείων
- Υπολογισμός εντροπίας Shannon για ανάλυση τυχαιότητας
- Two-Factor Authentication (2FA) με One-Time Passwords (OTP)
- Χρήση `salt` για ενίσχυση της ασφάλειας hashing
