# Linux User Management

Σύνολο scripts για τη διαχείριση χρηστών, ομάδων και δικαιωμάτων σε
συστήματα Linux, με έμφαση στην ασφάλεια (principle of least privilege,
auditing, sudo policies).

## Ενδεικτικά θέματα

- Δημιουργία/διαγραφή χρηστών και ομάδων
- Ρύθμιση δικαιωμάτων αρχείων (`chmod`, `chown`, ACLs)
- Πολιτικές `sudo` και περιορισμός προνομίων
- Auditing ενεργειών χρηστών

## Εκτέλεση

```bash
cd Linux-user-management
chmod +x *.sh
sudo ./<script>.sh
```
