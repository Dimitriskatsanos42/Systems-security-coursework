# Password Strength Checker

Μικρό CLI εργαλείο που εκτιμά την ισχύ ενός κωδικού πρόσβασης, βασισμένο σε
αρχές που παρουσιάστηκαν στην [1η εργασία](../assignment-1-hashing-2fa)
(εντροπία) και επεκτείνει την ιδέα σε πρακτική αξιολόγηση κωδικών.

## Τι κάνει

- Υπολογίζει το **μήκος** και τα **σύνολα χαρακτήρων** (πεζά/κεφαλαία/ψηφία/σύμβολα)
- Εκτιμά την **εντροπία σε bits** (πόσο μεγάλος είναι ο χώρος πιθανών κωδικών)
- Ελέγχει αν ο κωδικός βρίσκεται σε λίστα **συνηθισμένων/αδύναμων κωδικών**
- Εκτιμά τον **χρόνο brute-force** σε 4 ρεαλιστικά σενάρια επίθεσης (online με/
  χωρίς rate-limiting, offline με αργό/γρήγορο hashing)
- Δίνει **συγκεκριμένες προτάσεις βελτίωσης**

## Γιατί είναι χρήσιμο αυτό

Δείχνει πρακτικά γιατί το μήκος και η ποικιλία χαρακτήρων δεν αρκούν από μόνα
τους — ένας κωδικός μπορεί να έχει "καλή" εντροπία με βάση το αλφάβητό του,
αλλά αν είναι γνωστή λέξη/μοτίβο (π.χ. `password123!`), στην πράξη σπάει πολύ
πιο γρήγορα απ' όσο δείχνει ο θεωρητικός υπολογισμός εντροπίας — γι' αυτό
ελέγχεται ξεχωριστά έναντι λίστας συνηθισμένων κωδικών.

## Εκτέλεση

```bash
python3 password_strength_checker.py
```

Δεν χρειάζεται καμία εξωτερική βιβλιοθήκη (μόνο Python 3 standard library).

### Παράδειγμα εξόδου

```
Μήκος: 15 χαρακτήρες
Σύνολα χαρακτήρων: πεζά, κεφαλαία, ψηφία, σύμβολα
Εκτιμώμενη εντροπία: 98.3 bits
Βαθμολογία: Πολύ Ισχυρός
Σε λίστα συνηθισμένων κωδικών: Όχι

Εκτιμώμενος χρόνος εξαντλητικής αναζήτησης (brute force):
  - Online, με rate-limiting (π.χ. 10 προσπάθειες/sec): πάνω από 6.27e+18 αιώνες
  - Offline, γρήγορο hash (απλό SHA-256/MD5, ~10 δισ./sec σε GPU cluster): πάνω από 6.27e+09 αιώνες

Προτάσεις βελτίωσης:
  • Καλή δουλειά — ο κωδικός καλύπτει τις βασικές συστάσεις.
```

## Σημείωση Ασφάλειας

Ο κωδικός **δεν αποθηκεύεται, δεν γράφεται σε αρχείο και δεν στέλνεται
πουθενά** — ελέγχεται μόνο τοπικά, στη μνήμη, κατά τη διάρκεια εκτέλεσης.
Χρησιμοποιείται `getpass` ώστε ο κωδικός να μην εμφανίζεται στο τερματικό.

## Περιορισμοί (για ειλικρίνεια)

- Η λίστα συνηθισμένων κωδικών είναι μικρή/ενδεικτική (~30 κωδικοί). Σε
  πραγματικό σύστημα θα χρησιμοποιούσε κανείς κάτι σαν το
  [Have I Been Pwned Passwords API](https://haveibeenpwned.com/Passwords) ή
  μια πλήρη λίστα τύπου `rockyou.txt`.
- Ο υπολογισμός εντροπίας θεωρεί τυχαία επιλογή χαρακτήρων από το αλφάβητο
  που χρησιμοποιείται· δεν εντοπίζει μοτίβα όπως "1234" ή keyboard walks
  (π.χ. "qwerty") πέρα από την απευθείας λίστα συνηθισμένων κωδικών. Ένα
  εργαλείο παραγωγής θα χρησιμοποιούσε κάτι πιο σύνθετο όπως το
  [zxcvbn](https://github.com/dropbox/zxcvbn) της Dropbox.
